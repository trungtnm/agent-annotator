# The prompt

**Copy prompt** puts one Markdown document on the clipboard. It is written for a coding agent:
what to do comes first, then one section per comment with the facts needed to find the code
without searching: the source line before the selector, the selector before the text.

## Fields

| Field | What it tells the agent |
|---|---|
| **Page** | Path and title where the comment was made. |
| **Kind** | For a group or an area: that the comment applies to every element listed. |
| **Element** | The opening tag (identity attributes only) and its visible text. |
| **Role (a11y)** | Role, accessible name and states, e.g. `button "Save" (disabled)`. |
| **Section** | The page heading and the labelled sections around the element. |
| **Nearby** | Neighbouring text, to tell identical elements apart. |
| **Selector** | A CSS selector that finds the element again. |
| **Element JSX** | The file:line:column where the element's JSX is written. Exact when mapped. |
| **Components, nearest first** | The component chain, each with where it is rendered. |
| **Position / Current style** | Size, place in the viewport and the computed styles that matter. |
| **Data of `Component`** | Props and state (in hook order) of the nearest components, personal data redacted unless [redaction](redaction.md) was off for the comment. Left out for components with neither, or when **Include props/state** is off. |

Paths are written from the repository root when you pass `appDir`.

The opening instructions say personal data has been replaced with `[redacted]`. If some
comments were recorded with [redaction](redaction.md) switched off, the sentence names them:
"(except in comments 2, 3, recorded with redaction off)". If all of them were, it is left out.
